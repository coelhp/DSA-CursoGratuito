## ▶️ Como Executar os Projetos:
 
### Pré-requisitos
 
- Python 3.8 ou superior instalado
- `pip` ou `conda` para gerenciamento de pacotes
 
### Passo a passo:
 
```bash
# 1. Clone este repositório
git clone https://github.com/coelho/DSA-CursoGratuito.git
cd DSA-CursoGratuito
 
# 2. Crie e ative um ambiente virtual (recomendado)
python -m venv venv
source venv/bin/activate        # Linux/macOS
venv\Scripts\activate           # Windows
 
# 3. Instale as dependências do projeto desejado
cd mini-projetos/01-analise-vendas-ecommerce
pip install -r requirements.txt
 
# 4. Execute o notebook ou script
jupyter notebook
# ou
python main.py
```
 
> Cada pasta de projeto possui seu próprio `requirements.txt` e um `README.md` explicando o objetivo, os dados utilizados e os resultados obtidos.
